Compatibility & hardware requirements

Built for the console and tuned for modern play.

Environment Compatibility Setup notes
Original N64 Fully supported Requires a flash cartridge (e.g. EverDrive) and the 8MB Expansion Pak.
Analogue 3D Fully supported Works flawlessly with Expansion Pak mode enabled in system settings.
PC / Mac / emulator Supported Run the .z64 ROM and ensure emulator memory is set to 8MB (Expansion Pak).
